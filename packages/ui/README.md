# packages/ui — sistema de diseño

Componentes React y tokens compartidos por `apps/www`, `apps/account` y `apps/download`.

- Tailwind CSS con una única escala de grises (`neutral`), sin colores de acento.
- Tokens como variables CSS; las apps no declaran colores propios.
- El énfasis se logra con peso, borde, opacidad y espaciado.

**Estado:** pendiente (Paso 3).
