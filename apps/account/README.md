# apps/account — identidad

Proyecto Astro + React para **`app.tchat.site`**.

- Registro, inicio de sesión, recuperación de contraseña y perfil.
- Página `cli-auth` donde el usuario aprueba el código del device flow del terminal.
- Usa Firebase Auth (SDK web) y `@tchat/api-client`.
- Se despliega en Vercel con *Root Directory* `apps/account`.

**Estado:** pendiente (Paso 3). El device flow real llega en el Paso 4.
