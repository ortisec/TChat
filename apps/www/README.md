# apps/www — landing

Proyecto Astro + React para **`tchat.site`**.

- Explica el producto, muestra capturas y enlaza a la cuenta y a las descargas.
- No carga Firebase ni el cliente de API.
- Se despliega en Vercel con *Root Directory* `apps/www`.

**Estado:** pendiente (Paso 3). Se crea con Tailwind y la escala de grises de `packages/ui`.
